# Ford < Enter > - Sprint 05: Manipulação de dados(DOM), com JavaScript.

Este repositório foi desenvolvido como parte da **Sprint 05** do curso de Front-End do programa **Ford < Enter >**, uma iniciativa realizada em parceria entre a **Ford** e o **SENAI/CIMATEC**.

## 🎯 Objetivo do Projeto
O foco principal desta etapa foi o treinamento prático de **manipulação de elementos e lógica de programação com JavaScript**. O objetivo foi consolidar na prática tudo o que foi passado durante a sprint.

> **Nota:** O projeto contido neste repositório foi criado exclusivamente para fins didáticos, não representando um projeto de software final ou funcional.

## 🛠️ Tecnologias e Ferramentas Exploradas
* **Git:** Controle de versão local (init, add, commit, branch, checkout, merge).
* **GitHub:** Hospedagem de repositório remoto e gerenciamento de commits.
* **JavaScript:** Lógica.
